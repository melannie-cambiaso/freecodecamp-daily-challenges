# FreeCodeCamp Daily Coding Challenges

My solutions to the [FreeCodeCamp Daily Coding Challenge](https://www.freecodecamp.org/learn/daily-coding-challenge/archive).

## About

This repository contains my solutions to FreeCodeCamp's daily coding challenges. Each challenge is designed to improve problem-solving skills and coding proficiency through consistent practice.

## Structure

Solutions are organized by year and month:

```
YYYY/
  MonthName/
    DD.challenge-name.js
```

## Challenges Completed

### 2026

#### January

- [03 - Left-Handed Seat at the Table](2026/January/03.left-handled.js) - Determine available seating for left-handed people at a table

## Running the Solutions

Each solution file can be run directly with Node.js:

```bash
node 2026/January/03.left-handled.js
```
